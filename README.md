
# 🛒 E-Commerce Sales Data Analysis Using Excel

## 📌 Project Overview

This project focuses on analyzing an E-Commerce Sales Dataset using Microsoft Excel to identify sales trends, customer purchasing behavior, product performance, and business insights.

The objective of this project is to transform raw sales data into meaningful insights using Excel functions, data cleaning, Pivot Tables, and an interactive dashboard.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Identify top-performing products and categories.
- Understand customer purchasing behavior.
- Analyze sales based on gender and loyalty levels.
- Evaluate store performance across different regions.
- Identify trends in customer transactions.
- Build an interactive Excel dashboard for business insights.

## 🧮 Excel Functions Used

The following Excel functions were used for data analysis:

| Function | Purpose |
|---|---|
| SUM | Calculate total sales |
| SUMIF | Calculate sales based on specific criteria |
| SUMIFS | Calculate sales using multiple criteria |
| COUNT | Count numerical values |
| COUNTIF | Count records based on conditions |
| AVERAGE | Calculate average values |
| AVERAGEIF | Calculate average based on criteria |
| IF | Apply logical conditions |
| MIN | Identify minimum values |
| MAX | Identify maximum values |
| VLOOKUP | Retrieve matching information |
| IFERROR | Handle formula errors |
